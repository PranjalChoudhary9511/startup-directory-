# Grant SOP: how every grant is documented

Every grant, scheme, fellowship or credits programme on the site is written to the same template, in the same order. A reader can compare any two grants line by line and decide in under five minutes whether to apply.

Machine version (enforced by the site): `web/src/content/grants/schema.ts`.

## The 6 rules

1. **No invented numbers.** Every figure (amounts, approvals, grantee counts, charts) has a source link and an "as of" date. If it isn't published, write "Not published". Never estimate silently.
2. **Official links only for applying.** "Apply" always points to the government or programme's own site, never a middleman or agent.
3. **Plain words.** Written for a Class 11 student and a 30-year-old first-time founder alike. No jargon without a one-line explanation.
4. **Decision first.** Every grant ends in a clear "Good fit if / Skip if". The goal is a decision, not a brochure.
5. **Honest cons.** Every grant lists real downsides: slow money, equity taken, paperwork, incubator dependence, low selection rates.
6. **Re-verify monthly.** Each entry shows a "last verified" date. Anything older than 90 days gets flagged on the site.

## The template (in display order)

| # | Section | What it answers |
|---|---|---|
| 1 | **Identity** | Official name, short name, who runs it, central/state/private/global, state, launch year |
| 2 | **At a glance** | Max amount, instrument (grant/loan/equity/credits…), equity taken, duration, time to money, status, deadline, stages, sectors |
| 3 | **What it is** | One plain sentence + 2–4 sentences on what it pays for |
| 4 | **Who can get it** | Eligibility bullets |
| 5 | **Who can't** | Disqualifiers people miss |
| 6 | **Why get it** | Reasons a founder should care, beyond the money |
| 7 | **How it works** | Who evaluates, how money flows, milestones |
| 8 | **Step-by-step process** | Ordered steps from preparation to first disbursement |
| 9 | **Documents** | A checklist to prepare before applying |
| 10 | **Benefits** | Money, mentoring, credibility, network, follow-on access |
| 11 | **Pros / Cons** | Honest trade-offs, side by side |
| 12 | **Good fit if / Skip if** | The decision helper |
| 13 | **Insider tips** | Practical tips that improve the odds |
| 14 | **Performance since launch** | Summary, key metrics, time-series charts, all sourced |
| 15 | **Apply** | Official apply link + official guidelines link |
| 16 | **Sources & trust** | Every source, last verified date, what couldn't be verified |

## Status labels

| Label | Meaning |
|---|---|
| **Open** | Applications accepted now |
| **Rolling** | Apply any time; reviewed continuously |
| **Call-based** | Opens in rounds; watch for the next call |
| **Closed** | Not accepting; may reopen |
| **Unverified** | We couldn't confirm the current status from an official source |
